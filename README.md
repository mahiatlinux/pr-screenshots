## Reproduction

The published Python scene scripts use `/task` as a disposable workspace containing exact `base`, `head` and `merge` checkouts and their `.venv` environments. `python-lock.txt` records the Python resolution; frontend dependencies use each checkout's lockfile.

Build each frontend with `npm ci --ignore-scripts --no-fund --no-audit` and `npm run build`. Launch the base and head via `launch_studio.py` on ports 18755 and 18756. Run `ui_scene.py`, followed by `ui_browser_matrix.py` with `REVIEW_BROWSER=firefox`, `webkit`, `chrome` or `msedge`. Run `download_ab.py` for the desktop-policy negative control. These scripts create disposable local sessions; they contain no saved credentials.

For fixture runs, use the PR's `tests/studio/playwright_inline_images.py`. The included `fixture-runner.py` and `fixture-server.mjs` adapt that fixture to read the complete base or merge checkout through `REVIEW_REPO`; they do not replace renderer source. Base runs use `--baseline c3329b9dbf2defc1e333dff30862e4bf31fb3718` and assert that the relative filename fails while the explicit URL passes.
